# File: gipcco_project/inventory/views/financials/docs/config_views.md

- **Purpose:** This file contains views related to financial configuration, such as cost pools and allocation drivers.

---

## `cost_pools_list(request)`

- **Purpose:** Manages the Cost Pool hierarchy (listing, creation, editing, and deletion).
- **Args:**
  - `request`: The HTTP request object.
- **Returns:** An HTTP response with the cost pools list.

## `allocation_drivers_list(request)`

- **Purpose:** Manages the Allocation Driver master list (listing, creation, editing).
- **Args:**
  - `request`: The HTTP request object.
- **Returns:** An HTTP response with the allocation drivers list.
