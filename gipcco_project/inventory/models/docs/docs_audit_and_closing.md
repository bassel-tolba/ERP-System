# File: gipcco_project/inventory/models/audit_and_closing.py
- **Purpose:** Defines models for auditing and managing the period-closing process.

- `PeriodClosingAuditLog`: Logs all status changes for a financial period for audit purposes.
- `PeriodCloseChecklist`: A checklist to guide and validate the period-closing process.
- `TransactionCorrection`: An audit model that records when a transaction from a closed period is corrected.
