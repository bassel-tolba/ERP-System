# File: gipcco_project/inventory/models/overhead_allocation.py
- **Purpose:** Defines models for calculating and allocating manufacturing overhead costs.

- `CostPool`: A hierarchical model for defining overhead cost pools.
- `AllocationDriver`: Represents a basis for allocating overhead costs (e.g., machine hours).
- `OverheadAllocationRun`: Represents a single run of the overhead allocation process.
